# 项目完善方案

依据：用户要求完善现有项目，附件《大作业.pdf》作为验收需求参考。
保留现有 LLM + ABC 双引擎及工作区已有 README、报告修改。

## 实施范围

1. 修复验证器的错误放行：形式验证只有 `proved` 可验收；有界检查、
   超时、跳过、工具错误和不可回放反例均保留证据并拒绝候选。
2. 默认严格波形验收，宽松模式必须显式开启；最终复核准备失败回退原设计。
3. 修复调用预算和并发限制，增加离线入口及 CLI 输入校验；
   批量任务隔离失败，输出目录唯一且遇失败返回非零状态。
4. 增加不依赖 LLM 的验收回归，执行真实 EDA 自检和端到端优化。
5. 从实际 result.json 生成结果表，补齐可复现结果、使用说明和 PDF 报告。

## 验证

- 单元回归覆盖形式验证异常、宽松候选反例、最终复核故障和 CLI 边界。
- 现有六项真实 Yosys / Icarus 自检必须通过。
- 真实模型联调和用例运行记录 token、耗时、面积、ltp 及证明证据。
- 报告区分本地复刻用例与官方测试，不把有限仿真或有界检查称为完整证明。
