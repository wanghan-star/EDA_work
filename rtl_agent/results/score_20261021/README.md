## 实现变化

1. 增加通用无符号进位融合、4/8 位分块先行进位及单点/全局候选。只识别有限、可验证的语法，不硬编码模块名或官方激励。
2. 对算术候选只做 dc2x3/syn2_dch 的降深度重综合，保留其他设计的完整 ABC 脚本组合。
3. 参数化输出默认配置在顶层内联，非默认参数回退原 RTL。恢复参数声明不能恢复已固定的位宽；本次对此进行了实际修复。
4. 参数名/默认值、端口符号性纳入接口检查；形式 unknown/超时拒绝；提供的官方激励编译失败或缺输出时拒绝验收。
5. 增加包含救援在内的 --max-calls 硬限制，尊重 LLM_MAX_TOKENS 与配置并发。
6. 独立课程复核检查完整性、全部激励、工具返回码，并记录输入/输出/激励/检查器哈希。

## 成本与复现边界

[`public/selection.json`](public/selection.json) 逐用例记录选中来源、所有提供的比较记录及其 token/耗时。表格中的 token/耗时仅为胜出运行；全搜索成本单列。旧快照是多轮择优而没有各轮完整成本，因此历史总成本只能给出已知部分，`search_costs_complete=false`。重综合原型探索、验证检查和报告生成也不属于表中优化运行时间。

复现命令见 [`../../README.md`](../../README.md)。全量离线基线用 `--offline --budget quick`；case7 最终配置为 `--offline --resynth fallback --no-relaxed --budget quick`。主模型 LIFO 用 `--budget normal --max-calls 5 --resynth off`；fp_rounding 用 `--budget quick --max-calls 3 --resynth off`。
